# ANDA

Static storefront concept for ANDA, a clothing brand focused on tops, lounge sets, and coordinated shirt-and-shorts or shirt-and-trouser sets.

## Local development

```bash
npm install
npm run build
npm run serve
```

Open `http://127.0.0.1:4173/`.

## Deployment

Pushes to `main` are built and deployed automatically through GitHub Pages.
